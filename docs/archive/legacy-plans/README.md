# Legacy Plans Archive

Folder ini berisi dokumen rencana/audit lama yang tidak lagi menjadi sumber kebenaran utama.

Dokumen dipindahkan ke sini karena beberapa klaim status di dalamnya sudah tidak cocok dengan kondisi kode saat ini. Contoh: Visual Editor dan Setup Wizard pernah ditandai selesai, tetapi audit terbaru menemukan compile error, route yang membingungkan, dan implementasi placeholder.

Gunakan folder ini hanya untuk membaca histori keputusan.
