# Webtokoku Interactive Demo

Demo ini adalah halaman statis untuk menjelaskan alur Webtokoku tanpa login.

Status:
- Harus terasa selaras dengan landing page utama: putih, hijau, slate, clean, dan fokus UMKM.
- Bukan sumber data production.
- Tidak memakai database atau auth.
- Link utama dari landing page mengarah ke `public/inidemo/index.html`.

Tujuan demo:
1. Menjelaskan proses membuat toko.
2. Menunjukkan pilihan template.
3. Menunjukkan gambaran editor template.
4. Menunjukkan katalog dan checkout WhatsApp.
5. Menunjukkan dashboard ringkas setelah publish.

Catatan:
- Jangan pakai gaya dark-indigo lama.
- Jangan klaim fitur yang belum stabil sebagai final.
- Untuk demo template live aktual, gunakan folder `public/demo/`.
